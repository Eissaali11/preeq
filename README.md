## 📌 نظرة عامة

**Bareeq Agency** هو موقع ويب إبداعي احترافي لوكالة تسويق رقمي. يتميز بتصميم عصري جذاب مع Hero Section متحركة وتأثيرات بصرية مميزة. الموقع منشور على **Firebase Hosting** ومتاح باللغتين العربية والإنجليزية.

```
╔══════════════════════════════════════════════════════╗
║           ✨ BAREEQ AGENCY WEBSITE                   ║
║                                                      ║
║  🌐 الموقع                                           ║
║  ├── index.html       ← الصفحة الرئيسية (عربي)      ║
║  ├── english.html     ← النسخة الإنجليزية           ║
║  │                                                   ║
║  🎨 التصميم                                          ║
║  ├── style.css        ← التنسيق الرئيسي             ║
║  ├── style-hero-new.css ← تنسيق Hero المتحركة       ║
║  └── assets/          ← الصور والموارد              ║
║                                                      ║
║  🔥 Firebase                                         ║
║  ├── firebase-config.js ← إعداد Firebase             ║
║  └── firebase.json    ← إعداد الاستضافة             ║
╚══════════════════════════════════════════════════════╝
```

## 🚀 طريقة التشغيل

### محلياً
```bash
# 1. نسخ المستودع
git clone https://github.com/Eissaali11/preeq.git
cd preeq

# 2. فتح الموقع مباشرة
open index.html

# أو باستخدام سيرفر محلي
npx serve .
```

### النشر على Firebase
```bash
# 1. تثبيت Firebase CLI
npm install -g firebase-tools

# 2. تسجيل الدخول
firebase login

# 3. نشر الموقع
firebase deploy
```
